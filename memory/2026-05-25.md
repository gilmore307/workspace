## Option sizing discretization rule

- C05 needs an explicit integer-contract discretization rule because option contracts can be too coarse for ideal dollar allocations.
- Agreed design direction:
  - C05 first receives/calculates the ideal allocation or current tranche notional.
  - For options, compute contract cost from premium/reference price times multiplier.
  - Default to rounding down to an integer contract count.
  - Permit rounding up only within a fixed oversize tolerance.
  - If even one contract exceeds allowed allocation/risk tolerance, fallback path is: C04 finds a still-qualified cheaper contract, otherwise use underlying-only expression if valid, otherwise skip/no-trade.
  - Never buy a lower-quality option just to fill allocation.
  - Unused allocation returns to cash/opportunity capacity instead of being forced into the same target.
